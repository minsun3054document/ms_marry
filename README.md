# 모바일 청첩장

사진의 따뜻한 빈티지 톤을 살린 반응형 단일 페이지 모바일 청첩장입니다.

## 실행

별도 설치 없이 `index.html`을 브라우저로 열 수 있습니다. 로컬 서버가 필요하면 Python이 설치된 환경에서 아래 명령을 실행하세요.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 정보 수정

`script.js` 상단의 `WEDDING` 객체에서 신랑·신부 이름, 예식 일시, 장소, 교통편, 계좌번호, 지도 링크를 한 번에 변경할 수 있습니다.

대표 공유 이미지와 검색/메신저 미리보기 문구는 `index.html`의 `og:*` 메타 태그에서 수정합니다.
